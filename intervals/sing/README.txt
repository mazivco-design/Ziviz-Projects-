Sung note samples (do re mi ...) used by "מרווח בקול".

Source: solfege-samples by wcgbg, voice "chengu"
https://github.com/wcgbg/solfege-samples
License: GNU GPL v3 (see LICENSE.txt in this folder).

Changes made here: trimmed to ~0.9 s, converted to MP3, and the black-key
notes (and a few slightly sharp notes) were re-pitched from the neighbouring
recording with a WORLD vocoder so every file is within a few cents of its note.
File name = MIDI note number (60 = middle C).
